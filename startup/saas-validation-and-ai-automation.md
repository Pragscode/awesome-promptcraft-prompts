# SaaS Validation and AI Automation Prompts

Use this pack for fast validation and automated operations design.

## Prompt 1: SaaS Validation Sprint Blueprint

### Prompt

```text
Role:
You are a lean startup validation specialist.

Task:
Design a 30-day validation sprint to prove demand for an AI note-to-action SaaS tool for remote teams.

Context:
- Hypothesis: teams will pay to convert meetings into prioritized task boards
- Founder has audience of 5,000 LinkedIn followers
- Product currently prototype-level
- Success target: 15 paid pilot users

Style:
Lean, experiment-driven, and customer-evidence oriented.

Constraints:
- Must include interview script and qualification rubric
- Must include pricing test strategy
- Must include landing page and messaging experiment
- Must include clear kill or continue criteria

Output Format:
1) Validation hypotheses
2) 30-day weekly plan
3) Evidence collection framework
4) Pricing and offer experiments
5) Decision criteria and next actions
```

### Expected AI Output

- concrete customer discovery workflow
- evidence-based validation thresholds
- clear go/no-go decision logic

## Prompt 2: AI Automation Backbone for Startup Ops

### Prompt

```text
Role:
You are an AI operations architect for early-stage startups.

Task:
Design an AI automation backbone that handles lead triage, onboarding emails, support tagging, and weekly KPI reporting.

Context:
- Tools: HubSpot, Notion, Slack, Gmail, Stripe
- Team: 5 people, no dedicated ops hire
- Risk concerns: wrong customer classification, bad automated messaging

Style:
Operationally specific and risk-aware.

Constraints:
- Define each automation workflow trigger and fallback path
- Include human approval checkpoints for high-impact actions
- Include monitoring metrics and alert thresholds
- Include rollout plan by priority

Output Format:
1) Automation workflow map
2) Integration and data flow design
3) Safeguards and manual overrides
4) KPI and monitoring framework
5) 6-week rollout plan
```

### Expected AI Output

- workflow-level automation map with clear trigger-action logic
- controlled rollout strategy minimizing automation mistakes
- measurable efficiency and quality metrics

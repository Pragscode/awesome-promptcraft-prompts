# Interaction and Product Thinking Prompts

## Prompt 1: Feature Concept Critique

### Prompt

```text
Role:
You are a product design critic with deep interaction design expertise.

Task:
Critique a proposed AI copiloting sidebar feature before engineering implementation.

Context:
- Feature intent: help support agents draft responses faster
- Risk: cognitive overload due to too many options
- Target metric: reduce response composition time by 25%

Style:
Sharp, user-centered, and experiment-driven.

Constraints:
- Identify cognitive load risks and trust risks
- Provide 3 simplified interaction alternatives
- Include instrumentation recommendations to measure impact
- Include anti-patterns to avoid

Output Format:
1) Concept strengths/weaknesses
2) Risk analysis
3) Alternative interaction models
4) Measurement framework
5) Recommendation
```

### Expected AI Output

- nuanced critique beyond visual design
- clear interaction alternatives with tradeoffs
- measurable evaluation strategy

## Prompt 2: End-to-End User Journey Redesign

### Prompt

```text
Role:
You are a service design strategist.

Task:
Redesign the full user journey from sign-up to first value for a B2B analytics product.

Context:
- Current time-to-value: 4.5 days
- Goal: reduce to under 24 hours
- Inputs available: support transcripts, activation events, churn interviews

Style:
Journey-centric and execution-ready.

Constraints:
- Include pre-signup expectation setting
- Include onboarding triggers and nudges
- Include failure recovery paths
- Include cross-functional dependencies

Output Format:
1) Journey map (current vs target)
2) Key friction points
3) Redesign interventions
4) Dependencies and owner matrix
5) 6-week launch plan
```

### Expected AI Output

- measurable path to improved time-to-value
- practical alignment across product, design, and support
- journey-level redesign, not isolated UI tweaks

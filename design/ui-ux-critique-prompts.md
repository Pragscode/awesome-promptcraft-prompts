# UI/UX Critique Prompts

This pack helps teams run professional product design critiques.

## Prompt 1: SaaS UX Conversion Critique

### Prompt

```text
Role:
You are a senior product designer and UX researcher.

Task:
Critique a SaaS onboarding flow and identify usability blockers reducing activation.

Context:
- Product: AI analytics dashboard
- Users: support managers
- Funnel issue: 42% users drop before connecting data source
- Evidence: session recordings, heatmaps, support tickets

Style:
Evidence-based, actionable, and non-generic.

Constraints:
- Map issues to UX heuristics
- Prioritize by impact x effort
- Include at least 5 concrete UI improvement suggestions
- Include one A/B test plan for top hypothesis

Output Format:
1) UX diagnosis summary
2) Issue table (severity, evidence, impact)
3) Prioritized fixes
4) Revised onboarding flow steps
5) Experiment plan and success metrics
```

### Expected AI Output

- specific friction points and rationale
- clear fix prioritization
- testable hypotheses for activation improvement

## Prompt 2: Design System Quality Audit

### Prompt

```text
Role:
You are a design systems specialist.

Task:
Audit a product UI for consistency, accessibility, and component reuse maturity.

Context:
- Platform: web app with 40+ screens
- Team: 2 designers, 6 frontend engineers
- Problem: inconsistent spacing, typography drift, duplicate components

Style:
Systematic and implementation-aware.

Constraints:
- Evaluate typography, spacing, color, states, and accessibility
- Include WCAG-related findings
- Provide phased remediation plan
- Include governance recommendations for scale

Output Format:
1) Current-state assessment
2) Consistency and accessibility findings
3) Component inventory strategy
4) 30-60-90 day remediation plan
5) Design governance model
```

### Expected AI Output

- concrete design debt map
- practical sequence for system cleanup
- accessibility findings tied to standards

# Study Systems and Concept Learning Prompts

Use these prompts to turn passive reading into deep understanding and retention.

## Prompt 1: Concept-to-Intuition Builder

### Prompt

```text
Role:
You are a master educator who simplifies complex technical concepts without losing rigor.

Task:
Explain database indexing from first principles and help me build intuition strong enough to solve applied questions.

Context:
- Learner has basic SQL knowledge
- Confusion around B-trees, hash indexes, and query planner decisions
- Goal is practical understanding for interviews and exams

Style:
Progressive, layered, and analogy-supported.

Constraints:
- Start from intuition, then move to formal understanding
- Include 3 progressive examples
- Include comparison table for index types
- Include self-check questions with answer key

Output Format:
1) Foundational intuition
2) Formal explanation
3) Progressive examples
4) Index comparison table
5) Self-check quiz + answers
```

### Expected AI Output

- beginner-friendly intuition plus technical precision
- examples that connect query behavior to index structure
- concise self-assessment segment

## Prompt 2: Weekly Study System Optimizer

### Prompt

```text
Role:
You are a productivity coach specialized in student learning systems.

Task:
Audit and redesign my current study routine for better focus, retention, and consistency.

Context:
- Current routine: late-night cramming, low retention
- Constraints: college classes from 9 AM to 4 PM
- Goal: maintain daily progress without burnout

Style:
Supportive, direct, and systems-oriented.

Constraints:
- Include a weekly template with protected deep-work slots
- Include review loops and rest protocols
- Include relapse recovery protocol for missed days
- Include metrics to track effectiveness

Output Format:
1) Routine diagnosis
2) Redesigned weekly schedule
3) Focus and review system
4) Burnout prevention protocol
5) Weekly metrics dashboard
```

### Expected AI Output

- clear diagnosis of failure points
- actionable weekly system with accountability metrics
- sustainable routine instead of extreme schedules
